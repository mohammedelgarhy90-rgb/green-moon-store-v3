تحديث إصلاح قائمة الموبايل والصفقات — Green Moon
1) ارفع public/index.html إلى نفس المسار في GitHub واستبدل الملف الحالي.
2) لا تستبدل worker.js أو wrangler.toml.
3) انشر من Cloudflare Workers ثم اختبر:
- فتح القائمة ثم اختيار المنتجات/العروض/المقالات/Green Moon Doctor؛ المفروض القائمة تقفل والقسم يظهر أسفل الهيدر مباشرة.
- افتح قسم الصفقات وجرب زر "عرض الصفقة التالية". الزر يفتح تفاصيل الصفقة التالية الموجودة في قائمة الصفقات المحفوظة.
ملاحظة: صورة البنت هي صورة البانر الرئيسي الحالي المخزنة في إعدادات الموقع. غيّرها من إعدادات البانر/الرئيسية في لوحة التحكم إلى الصورة التي تريدها. لم أغير صور النباتات أو بيانات المنتجات.
تم فحص بناء JavaScript المضمن بشكل نحوي فقط؛ لم يتم النشر أو إجراء اختبار متصفح مباشر.
