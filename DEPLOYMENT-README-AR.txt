حزمة Green Moon النظيفة للنشر

تم الاحتفاظ بملفات التشغيل الحالية: worker.js وwrangler.toml وpackage.json ومحتويات public وإعداد GREEN_MOON_KV كما هو. تم استبعاد أرشيفات ZIP القديمة والنسخ الاحتياطية وملفات README المكررة ذات الأسماء التالفة وصفحة اختبار منفصلة لتقليل حجم وفوضى المشروع.

خطوات النشر الآمن:
1) راجع الملفات مقارنة بمستودع GitHub الحالي قبل الاستبدال.
2) لا تغيّر GREEN_MOON_KV أو معرّف مساحة التخزين.
3) انشر نسخة Preview على Cloudflare أولًا.
4) اختبر الصفحة الرئيسية والصور والبحث والعروض والسلة وإتمام الطلب وتسجيل دخول الإدارة والحفظ والطلبات والتتبع والموبايل.
5) بعد نجاح الاختبار فقط، انشر على الإنتاج.

الفحص المنفذ: فحص الصياغة باستخدام Node.js لملفات JavaScript والسكريبتات المضمنة في HTML. لم يتم اختبار المتصفح الحي أو تنفيذ طلب حقيقي أو النشر على Cloudflare.
